# VOXMATE_AI_ASSITANT


VoxMate is an AI-based assistant with face authentication and intelligent agent capabilities.

## 🚀 Features

* Face authentication using DeepFace
* AI agent for smart responses
* Modular tool system

## 🛠 Tech Stack

* Python
* DeepFace
* OpenCV

## ▶️ How to Run

```bash
git clone https://github.com/your-username/voxmate.git
cd voxmate
pip install -r requirements.txt
python agent.py
```

## ⚠️ Notes

* Add your API keys in `.env` file
* Do not upload `.env` to GitHub
